# SignSpeak AI

SignSpeak AI is a futuristic hand sign recognition web app that uses MediaPipe Hands and TensorFlow.js to detect gestures, display meanings, build text sentences, and speak recognized signs aloud.

## Features

- Real-time webcam hand sign recognition
- Glassmorphism dashboard with neon AI styling
- Live detection panel and sign dictionary
- Voice output with speech synthesis
- Session analytics and download report
- Screenshot capture and fullscreen camera mode

## Usage

1. Open `index.html` in a browser that supports webcam access.
2. Click **Start Detection**.
3. Allow camera access and display gestures in front of the webcam.
4. Use the dictionary search to explore sign meanings.

## Tech Stack

- HTML5
- CSS3 + Tailwind CSS
- JavaScript
- MediaPipe Hands
- TensorFlow.js
- Web Speech API

## Notes

For best results, use Chrome or Edge with a good webcam and a well-lit environment.
